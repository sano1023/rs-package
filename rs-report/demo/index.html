rs-report 依存ゼロの帳票エンジン — SVF / ActiveReports JS 代替　|　GUI デザイナを開く →

帳票定義（JSON）＋データ配列から、mm 精度のバンドレイアウトで自動改ページ・グループ集計・ページ繰越つきの帳票を組版します。 「印刷」ボタンで @page 実寸のまま印刷できます（PDF に保存すればそのまま PDF 出力）。

1. 請求書（適格請求書対応・80行の自動改ページと繰越）

キーボード: PageUp/PageDown でページ送り、+/− でズーム、0 で幅に合わせる

2. 宛名ラベル・タックシール面付け（v0.2 多段組）

1データ行 = 1ラベル。`columns` 指定で detail バンドが左→右に面付けされます。プリンタ側は「実際のサイズ」で印刷してください。

3. 帳票定義を JSON で編集 → ライブ反映（グループ集計の例）
