rs-editor v0.9 デモ — 依存ゼロ・プラグイン式WYSIWYGエディタ

v0.9：大きなアイコン・キャプション付きボックス・リンクカードを追加しました。見出しを書き換えると目次が更新されます。ボックスをクリックすると、設定・囲み解除・外側への段落追加ができます。
目次・ボックス専用デモ ／ 外部操作・タッチ操作デモ
標準機能（〜v0.2）: undo / redo・書式・文字色 / 背景色・見出し・配置・引用・コードブロック・リスト・インデント・リンク・画像（アップロード / リサイズ）・表・HTMLソース表示・フローティングツールバー・Markdownショートカット。
v0.3 の opt-in プラグイン: 特殊文字・絵文字・日付挿入・NBSP・検索置換（Ctrl+F）・プレビュー・ブロック可視化・全画面・アンカー・動画埋め込み・目次（見出しから自動生成）・文字数カウント・自動リンク・下書き自動保存。最後の「⭐」はカスタムプラグインの例です。
v0.5 の新機能: 空の段落で「/」を押すとスラッシュコマンド、段落ホバーで⠿ドラッグ並べ替え。ツールバーにチェックリスト・コールアウト・書式ペインター・脚注・コメント・リビジョン履歴（差分付き）・ルビ・文字種変換・日本語校正・縦書きプレビューを追加。
v0.6 の新機能: 区切り線（ツールバーの ─ ボタン）。プリセットから挿入するか「スタイルを指定して挿入…」で色・太さ・線種・幅をプレビューしながら設定できます。挿入した線はクリックで選択、ダブルクリックで再編集、Backspaceで削除。
